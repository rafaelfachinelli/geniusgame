## :information_source: About

🧠 A memory game inspired by the classic GENIUS (Simon). The game lights up a random color sequence and the player repeats it; every round adds one more color, with no limit. It has sound effects with an on/off switch.

|Action|Desktop|Mobile|
|:---:|:---:|:---:|
|Select a color|<kbd>Mouse click</kbd>|:x:|

Built in 2020.
